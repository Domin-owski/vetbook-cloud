Dokumentacja VetBook Cloud

Katalog zawiera dokumentację architektury trójwarstwowej projektu VetBook Cloud w Microsoft Azure.

## Pliki

- [`architecture.md`](architecture.md) - szczegółowy opis sieci, warstw i zabezpieczeń,
- [`architecture-3tier.svg`](architecture-3tier.svg) - diagram architektury w formacie wektorowym,
- [`architecture-3tier.png`](architecture-3tier.png) - diagram architektury w formacie PNG.

Projekt wykorzystuje Azure Virtual Network, trzy odseparowane podsieci, Network Security Groups oraz tabelę tras blokującą bezpośredni dostęp do Internetu z warstw prywatnych.
